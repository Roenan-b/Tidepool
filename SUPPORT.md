# Support

Tidepool is maintained by one person and offers no guaranteed support.

- **Questions and bugs:** open an [issue](https://github.com/Roenan-b/Tidepool/issues/new/choose) using one of the templates. Search existing issues first.
- **Security problems:** never use a public issue. See [SECURITY.md](SECURITY.md).
- **Setup help:** start with the [README](README.md), especially "Quick start (paper mode)", "Configuration" and "Known limitations".

Issues about losses from live trading, third-party services (RPC providers, Jupiter, data providers) or deployments that ignore the README's setup guidance are out of scope.
